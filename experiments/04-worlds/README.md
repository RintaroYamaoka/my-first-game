# 実験 2c: 潜った先は、別の世界

実験 2b(`03-scape`)は「中身は、外から見た形の中に縮小されて入っている」前提だった。
そのため、中の世界が外の形の枠に閉じ込められて、世界に見えなかった。

この実験は前提を変える。

- **外から見た形は、入口の姿。** 中の世界の輪郭ではない。
- **潜った先は、それだけで果てのない世界。** 広さも、並び方の法則も、空気(色)も、世界ごとに違う。
- 形と配置の規則(`docs/concept.md`)は変えない。規則は、世界ごとに持つ。

## 世界の法則

| 世界 | 法則 | 本物との対応 |
|---|---|---|
| プロジェクト(Pillars) | 柱が並ぶ | 上下 = 依存の向き。柱の高さ = 行数。帯 = 中の宣言の区切り |
| ファイル(Strata) | 下へ降りていく段丘。左右と奥へ果てなく続く | 段の順 = 書かれた順。段の高さ = 行数 |
| 関数(Road) | 前へ進む道。文は、くぐる門 | 門の奥行き = 行数。分岐で道が分かれる。`return` は道をふさぐ壁。else がない側は、道がなく線だけ |
| ループ(Ring) | 道が輪になる | 進むと、元の場所に戻る |

中に世界を持つもの(関数、ループ、関数を渡す呼び出し)は、道の真ん中に立つ塊になる。

## 操作(一人称視点のゲームと同じ)

| 操作 | 動き |
|---|---|
| マウス | 見回す(最初のクリックで、マウスをつかむ) |
| W / S | 見ている向きへ前進 / 後退(上を見て進めば、上がる) |
| A / D | 横へ |
| Shift | 速く |
| Space | 照準の先の、すぐ手前へ瞬間移動(先に何もなければ、まっすぐ前へ) |
| 移動キー + Space | その向きへ瞬間移動(40m) |
| 左クリック / E | 照準の先に潜る |
| 右クリック / Q | 上の世界へ戻る |
| Esc | マウスを放す |

## 動かし方

```sh
cargo run -p worlds -- experiments/01-world-from-code/sample           # WSL の窓
./scripts/run-windows.sh worlds experiments/01-world-from-code/sample  # Windows(GPU)
```

自動で潜って 1 枚撮る(確かめるため):

```sh
GO=store.ts,find,for SHOT=out.png cargo run -p worlds -- experiments/01-world-from-code/sample
```
