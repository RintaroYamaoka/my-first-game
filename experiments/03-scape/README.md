# 実験 2b: 本物のコードから組み立てた世界を、世界として見せる

段階 1(技術検証)の実験。`prototypes/scape/`(Web の試作)の世界らしさを、本物のコードと Bevy で再現できるかを確かめる。

**通過条件: 本人が「scape と同じくらい世界っぽい」と言えること。** → 2026-11-16 本人「世界っぽさは良い。操作性が悪いけど」。
世界っぽさは通過。操作性は未解決(どこが悪いかを確認中)。

## 動かし方

```
./scripts/run-windows.sh scape experiments/01-world-from-code/sample    # Windows で(GPU を使う)
cd experiments/01-world-from-code && cargo run -p scape -- sample       # WSL の窓で
```

操作: `←` `→` 選ぶ / `Enter` 潜る / `Backspace` 戻る / クリックで選ぶ(選んだものをもう一度クリックで潜る)/ 右クリックで戻る

自動で操作して画面を撮る: `KEYS=Right,Enter,Right SHOT=out.png cargo run -p scape -- sample`

## 入っているもの

- 実験 1(ファイルと依存パッケージの読み取り、上下 = 依存の向き、水平 = 結びつき)と、
  実験 2(本物の構文解析、積層・分岐・輪)を、一つの入れ子の世界にした
- **切り替えなしで拡大して潜る。** 中のものは外のものに対して縮小してあり、潜ると中が広大になる。
  位置と縮尺は倍精度で持ち、視点の近くだけを描画用の数に直す
- **全部を画面に収めない。** 視点は選んだものの近くにいる
- **遠くが霞む。霞みきらない。** 潜っても、外の柱が薄い影として残る。霞の濃さは視点の距離に対する割合で決めているので、
  どの深さでも同じように霞む
- 面の明るさを 3 段(上は白、手前は薄い灰、横は灰)にし、黒い輪郭線を付けた。選んだものは赤い太い線
- 柱(ファイル)は、中に入ると面が消えて、線だけの枠になる

## まだ入っていないもの

- 裏の黒い面(本物のコードが映る)。Bevy では、文字を 3D の面に貼る仕組みが別に要る
- 値(実行しないと分からない)
- フォルダ。今は、ファイルと依存パッケージが同じ層に並んでいる
- 依存パッケージの中(`prototypes/scape/` では巨大な街だった。規則どおりに置くと、足元に層になって沈む)
- 画面の左上の道筋は英数字だけ。日本語の説明文は出していない(同梱のフォントが英数字だけのため)
- 音

## 気づいたこと

- サンプルのプロジェクトが小さい(10 ファイル、48 パッケージ)。世界の広さは、読ませるプロジェクトの大きさで決まる
- 一番上の層から見下ろすと、下の層と依存パッケージは画面の外になる。縦に長い世界をどう見せるかは、要検討
